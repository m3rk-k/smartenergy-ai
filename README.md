# SmartEnergy AI

A Python app that analyzes hourly electricity usage, forecasts the next days and gives energy saving recommendations.

## Setup

1. Create a virtual environment:

   ```
   python -m venv venv
   ```

2. Activate it:

   ```
   venv\Scripts\activate
   ```

   On Mac or Linux use `source venv/bin/activate`.

3. Install the requirements:

   ```
   pip install -r requirements.txt
   ```
